# Feature 130 — Realtime UX + Streaming Visibility

## Goal
Deliver realtime user experience for job status, partial outputs, and progress at job and season levels.

## Includes
- Realtime channel for job events.
- UI status indicators for queue/running/success/failure/cancelled.
- Live log/partial token display.
- Season-level progress view across active advisor work.

## Acceptance Criteria
- Users see job state changes without manual refresh.
- Live partial output/log visibility is available while jobs run.
- Season progress gives clear completion visibility for advisor work.
